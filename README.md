# 柔光壁纸

一个离线运行的 Windows 小工具：把固定图片壁纸调暗，并可恢复本轮修改前的壁纸及显示方式。适合觉得桌面壁纸过亮、但不想改变屏幕亮度的场景。

## 功能

- 读取当前壁纸，或选择 JPG、PNG、BMP 等图片。
- 在 0%～75% 之间预览调暗效果，按住按钮对比原图。
- 一键应用到桌面，关闭程序后无需后台常驻。
- 恢复本轮首次应用前的壁纸及填充、适应、拉伸等显示方式。
- 单独导出调暗后的 PNG，不更改桌面。

原图片不会被修改；每次调整都以原图计算，避免反复调暗。

## 下载与使用

从 [Releases](https://github.com/cd5239/soft-wallpaper-dimmer/releases) 下载 `柔光壁纸-v1.0.zip`，解压后运行 `柔光壁纸.exe`。适用 Windows 10/11，使用系统自带的 .NET Framework 4.x；不需要管理员权限或联网。

1. 点击“读取当前壁纸”或“选择图片”。
2. 调节“调暗程度”，建议从 25% 开始。
3. 点击“应用到桌面”。需要撤销时，重新打开程序点击“恢复原壁纸”。

仅拖动滑块不会修改桌面。详细操作见 [使用说明](docs/使用说明.txt)。

## 适用范围与本地数据

此版适合固定图片及手动换图，不持续跟随 Windows 幻灯片或第三方壁纸程序自动换图。多显示器使用同一张壁纸；不会备份和恢复每块屏幕各自不同的图片。它只调整壁纸图像，不改变显示器亮度、窗口或任务栏。

设置、原壁纸恢复副本和调暗图片保存在 `%LOCALAPPDATA%\SoftWallpaperDimmer`。使用期间请保留该目录；卸载前先恢复原壁纸，或在 Windows 设置中另选壁纸。

## 从源码构建与验证

在 Windows PowerShell 中运行：

```powershell
.\source\build.ps1
```

脚本调用系统 .NET Framework 的 C# 编译器，在仓库根目录生成 `柔光壁纸.exe`。源码只使用 Windows 和 .NET Framework 自带 API。

源码内置不修改真实桌面的自检，可在独立目录运行：

```powershell
.\柔光壁纸.exe --self-test .\test-output
Get-Content .\test-output\test-result.txt
```

该自检覆盖像素调暗、原图不变、跨启动恢复、失败回滚等 16 项检查。实际桌面显示效果仍以使用者首次应用后的观察为准。
