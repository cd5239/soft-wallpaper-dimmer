柔光壁纸 1.0

双击“柔光壁纸.exe”即可运行，无需安装、管理员权限或网络。
适用于 Windows 10 / 11 自带的 .NET Framework 4.x 环境。

使用方法
1. 点击“读取当前壁纸”，或者“选择图片…”选择 JPG、PNG、BMP 等图片。
2. 拖动“调暗程度”滑块（0%～75%），建议先试 25%。
3. 按住“按住看原图”按钮，对比原图与调暗效果。
4. 点击“应用到桌面”。应用后可直接关闭工具，无需后台常驻。
5. 想撤销时，重新打开工具，点击“恢复原壁纸”。
   恢复的是本轮首次应用前的壁纸及填充/适应/拉伸等显示方式。

也可以点击“另存调暗图片…”，只导出 PNG，不更改桌面。
滑块只影响预览，点击“应用到桌面”才会更改 Windows 壁纸。
每次调整都从未调暗的图片生成，避免反复变黑。原图片不会被修改。
保留原始像素尺寸；预览为完整图片，实际桌面沿用 Windows 的填充方式。

适用范围
- 此版本用于固定图片、手动换图。
- 不持续跟随 Windows 聚焦、幻灯片或第三方工具自动更换的壁纸。
  如正在使用这些模式，请先在 Windows 设置 → 个性化 → 背景中选择“图片”。
- 适用于单显示器，或多个显示器共用同一张图片。
  应用会使用同一张图片，不备份/恢复多屏各自不同的壁纸配置。
- 仅调暗壁纸图像，不调整显示器亮度、窗口、图标或任务栏。

恢复文件
程序的设置、原壁纸恢复副本及调暗图片保存在：
%LOCALAPPDATA%\SoftWallpaperDimmer
应用期间请保留这个目录。程序退出后 Windows 仍需读取里面的壁纸。
原图被移动或删除时，会使用保存的恢复副本。
要彻底移除工具，先点击“恢复原壁纸”或通过 Windows 另设一张壁纸，
再删除程序和上述目录。若恢复时使用了副本，请先另设壁纸再删除目录。

验证说明
已检查界面渲染，并通过 16 项自动检查：像素调暗、原图不变、重复调节、
跨启动恢复、系统操作失败回滚、原图缺失时副本恢复、无图片背景恢复等。
系统写入使用模拟接口测试，制作过程中未修改用户实际桌面。
实际桌面效果以首次点击“应用到桌面”后的显示为准。

源码与构建
源码在 source 文件夹。右键 source/build.ps1，选择用 PowerShell 运行，
或在 PowerShell 中执行该脚本。构建仅使用系统 .NET Framework 编译器。
